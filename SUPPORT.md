# Support

Drovik is a volunteer-maintained open-source project.

- **Questions and usage help:** open a GitHub Discussion or an issue with the `question` label.
- **Bug reports:** use the bug report template and include the version, environment and safe
  reproduction steps. Never include secrets or real hostnames.
- **Security issues:** follow [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Feature requests:** use the feature request template and reference the relevant PRD
  requirement if one exists.

## Before asking

1. Read the [README](README.md) and [development setup](docs/development/setup.md).
2. Search existing issues and discussions.
3. Check the [compatibility matrix](docs/product/PRD.md) and known limitations.
4. Reproduce on the latest `main`.

## What we cannot support

- Recovering lost SSH credentials without the encryption key.
- Managing remote hosts without SSH access.
- Production emergencies on your servers.
- Private/custom deployment consulting.

## Response expectations

There is no guaranteed response time. Security reports are prioritised; general issues are handled
as maintainer capacity allows.
