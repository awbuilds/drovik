# 2026-11-08 Phase 4 SFTP file manager

## Task / Area
Implement the SFTP file manager, streamed transfers, path/symlink safety, recursive-delete
guards and the bounded text editor.

## Current State
- Backend:
  - `internal/files` service: list, stat, read, write, mkdir, touch, rename, delete, upload,
    download.
  - Absolute-path normalization; symlinks are identified but never followed by the editor or
    recursive delete.
  - Uploads and editor saves use a temporary remote file plus rename; partial files are cleaned up.
  - Editor reads are bounded and binary-detected (NUL/UTF-8); stale saves compare mtime and size.
  - Recursive delete is bounded by depth and entry count; symlinks are removed, not traversed.
  - Download streams with `Content-Disposition`, `no-store`; uploads use multipart streaming.
  - `SFTP_PERMISSION_DENIED`, `SFTP_UNAVAILABLE`, `FILE_TOO_LARGE`, `FILE_BINARY`, `FILE_STALE`
    and conflict errors are mapped to stable API codes.
- Frontend:
  - Files page with server selector, breadcrumbs, listing metadata, dotfile toggle, filter,
    sorting, refresh, upload (XHR progress), download, new folder/file, rename and delete.
  - Delete dialog with an explicit recursive checkbox and warning.
  - Bounded text editor with unsaved-change confirmation, stale-file error + reload, and explicit
    Save.
  - Upload collision prompts an overwrite confirmation.
  - Files route is lazy-loaded.
- Tests:
  - Service tests: list/read/write/stale, binary/size limits, mkdir/touch/rename/recursive delete,
    upload/download/conflict, invalid paths and symlink rejection.
  - HTTP test: listing, content read/write/stale/CSRF, mkdir/touch/rename/delete, upload/download
    and invalid path.
  - Frontend helper tests for paths, breadcrumbs, sorting, byte formatting and hidden files.
- Manual browser review: listed a test directory, opened a file, edited and saved it; the remote
  file content changed on disk.

## Decisions
- Remote paths must be absolute; `path.Clean` normalizes them and SFTP permissions remain the
  authority. No shell is used for file operations.
- Symlinks are shown but not opened in the editor and never followed by recursive operations.
- Editor saves are version-checked by mtime and size.
- Uploads and saves stage to a temp remote file and rename atomically where SFTP supports it.
- Download progress is delegated to the browser download manager; upload progress is in-app.
