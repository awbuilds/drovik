release assets for the public beta.

  - Storage test proves a second user's events are not visible.

    processes, services and logs.

- Documentation:
  - Stable error-code catalog, compatibility matrix, troubleshooting, backup/restore and security
    testing guides.
  - Beta notes with known limitations, upgrade and audit-retention guidance.
- Release:
  - Tag-driven workflow builds linux amd64/arm64 archives with version metadata, SHA-256 checksums,
    a GHCR image and a GitHub release; stable tags also update `latest`.
- Tests:
  - HTTP activity flow is covered inside the operations integration test.
  - Audit user scoping has a dedicated storage test.
  - Full `make verify` passes.

## Decisions
- Audit history is scoped without RBAC: the current user sees events they acted on or events for
  servers they own. There is no mutation API.
- Audit retention remains operator-managed; the beta notes document a safe cleanup pattern.
- Release archives include the frontend build so the binary can run without a separate web root.
- Prerelease tags do not update the `latest` container tag.
